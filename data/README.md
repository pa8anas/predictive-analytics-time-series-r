# Data

This directory contains organized copies of the external data files used by the analyses.

- `open-meteo-37.93N22.83E37m.csv` — historical rainfall observations downloaded from Open-Meteo for the Zevgolatio/Corinthia analysis.
- `unemployment_spain.txt` — monthly Spanish unemployment values used in Exercise 1.

The original uploaded files remain in the repository root unchanged.

## Reproducibility note

The weather dataset is an external historical-data snapshot. Keeping the raw downloaded file in the repository makes the coursework analysis reproducible even if the upstream API later changes.
