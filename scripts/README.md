# Analysis scripts

This directory contains organized R-script copies of the three original analysis files.

- `exercise1_unemployment.R` — Spanish unemployment time-series analysis and ARIMA forecasting.
- `exercise2_rainfall.R` — rainfall aggregation, stationarity/seasonality analysis, SARIMA modelling and forecasting.
- `exercise3_time_series_models.R` — AR(2) `cmort`, global-temperature ARIMA, and beer-sales decomposition.

The original `ask1.txt`, `ask2.txt`, and `ask3.txt` files remain in the repository root unchanged.
